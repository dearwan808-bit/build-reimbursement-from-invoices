# 发票报销单生成器

**Build Reimbursement From Invoices** 是一个面向 Codex 的财务工作流 Skill。上传发票、收据、车票或其他费用凭证后，它会整理逐票明细、检查异常并生成可审计的 Excel 报销单。

## 主要能力

- 批量盘点 PDF、图片、扫描件、表格和 ZIP 压缩包中的费用凭证
- 提取发票号码、日期、销售方、购买方、项目名称、不含税金额、税额和价税合计等字段
- 对关键金额进行视觉复核，保留原文件名与页码定位
- 按“发票代码＋发票号码”或票据指纹识别重复报销风险
- 区分员工垫付、公对公付款、备用金、公司卡等资金路径
- 将不可读、缺字段、待验真、重复候选和支付路径异常集中列入核验清单
- 按币种分别计算已核验票面小计和已确认可报销小计
- 只有全部金额、重复项和报销判断均已解决时，才给出最终报销合计

## 生成结果

Skill 会生成一个 Excel 工作簿，通常包含三张表：

1. **报销单**：报销人、部门或项目、用途、凭证数量、核验小计、可报销小计、异常数量和最终状态。
2. **发票明细**：每张发票或票据一行，记录金额、税额、发票号码、费用类别、支付路径、核验状态和来源定位。
3. **核验清单**：集中展示不可读文件、缺失字段、重复候选、支付路径问题和税务验真状态。

## 财务安全规则

- 文件名只能作为线索，不能作为金额或发票号码的最终证据。
- 金额必须经过可视化核验；无法辨认的票据不会被计入最终报销金额。
- 公对公已支付、已报销或已完成备用金核销的费用，不会自动作为员工报销处理。
- 重复识别结果只是候选提示，必须保留原始记录并完成确认。
- 文档核验不等同于税务平台验真；未取得正式验真结果时会标记为“未验真”。
- 多币种不会混合为一个合计，除非另有明确汇率规则和来源。

## 安装

将仓库克隆到 Codex Skills 目录：

```bash
git clone https://github.com/dearwan808-bit/build-reimbursement-from-invoices.git ~/.codex/skills/build-reimbursement-from-invoices
```

安装完成后重启 Codex，使新 Skill 被加载。

本 Skill 会配合 Codex 的 `pdf` 和 `spreadsheets` Skill 完成 PDF 视觉检查与 Excel 生成、公式检查和页面渲染。

## 使用方法

上传发票文件后，可以直接输入：

```text
使用 $build-reimbursement-from-invoices 处理我上传的发票，并生成可核验的 Excel 报销单。
```

也可以使用自然语言：

```text
把这些发票整理成报销单，列出每张票的明细、异常情况和合计金额。
```

## 仓库结构

```text
build-reimbursement-from-invoices/
├── SKILL.md
├── agents/
│   └── openai.yaml
├── references/
│   └── invoice-schema.md
└── scripts/
    └── validate_reimbursement_rows.py
```

其中 `validate_reimbursement_rows.py` 使用十进制定点计算检查金额、重复项、支付路径和最终合计条件，避免人工汇总造成精度或遗漏问题。

## 适用范围

适合日常费用报销、差旅票据整理、项目费用归集、发票台账准备和报销前财务复核。实际使用时仍应结合所在公司的报销制度、审批要求和税务规范。
